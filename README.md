# YURIM AI COMPANY · Pixel Office

31명의 동물 직원과 사람 대표가 일하는 2D 파스텔 픽셀 오피스입니다. 첫 방문에는 전원이 출입구에서 각자 자리까지 도착한 뒤 아침 업무를 시작합니다. 같은 날 새로고침하면 현재 단계와 회의록을 복원하며 출근부터 다시 시작하지 않습니다. 두 활동팀의 TOP 10 전체 리포트가 매일 기본 산출물이며, 대표는 원하는 팀에 추가 업무를 보낼 수 있습니다.

## 지금 자동으로 하는 일

- VMware팀: William Lam과 VMware/Broadcom 공식 피드에서 최신 버그·이슈·업그레이드 후보 10개 조사
- IT트렌드팀: OpenAI, Google AI, NVIDIA, AWS ML, CNCF 공식 피드에서 AI 트렌드 10개 조사
- 두 팀은 편집회의 성공 여부와 관계없이 매일 10개 수집 원본을 각자 Obsidian 파일로 먼저 저장
- 브랜드 분석팀·검수팀: Codex 편집회의로 20개를 100점 기준 전수 평가하고 중복·출처·버전을 검수
- 비서실: 두 팀의 TOP 10 전체 리포트와 선택형 심화노트 추천 3개 정리
- 대표: TOP 10 전체를 읽고, 필요할 때만 추천 항목을 긴 기술노트로 작성
- 새 업무 시키기: 팀과 업무 내용을 보내면 Codex가 실제 Markdown 산출물을 만들고 옵시디언에 저장
- Kubernetes팀·Linux팀: 정기 업무는 미지정이지만 대표의 추가 업무는 바로 수행

## 옵시디언 볼트와 연결해서 실행

`run-local.command`를 더블클릭하거나 터미널에서 아래처럼 실행합니다.

```bash
./run-local.command
```

브라우저에서 `http://localhost:4173`을 열면 현재 볼트가 연결됩니다.

- `01_아이디어/YYYY-MM-DD/VMware팀-리서치.md`
- `01_아이디어/YYYY-MM-DD/IT트렌드팀-리서치.md`
- `01_아이디어/YYYY-MM-DD/VMware팀-수집원본.md`
- `01_아이디어/YYYY-MM-DD/IT트렌드팀-수집원본.md`
- `01_아이디어/YYYY-MM-DD/브랜드분석-검수보고서.md`
- `01_아이디어/YYYY-MM-DD/추가업무/*.md` — 대표가 보낸 추가 업무의 실제 산출물
- `02_기술노트/YYYY-MM-DD-선택안-기술노트.md` — 선택형 심화노트 작성 뒤 생성
- `03_성과기록/YYYY-MM-DD-대표결정.md` — 심화노트 선택 기록

다른 옵시디언 볼트를 연결하려면 환경변수로 절대 경로를 지정합니다.

```bash
AI_COMPANY_VAULT="/path/to/Obsidian Vault" ./run-local.command
```

GitHub Pages는 브라우저 보안상 컴퓨터의 로컬 파일을 쓸 수 없으므로 읽기 전용 데모입니다. 실제 조사와 옵시디언 기록은 로컬 콘솔에서 처리하며 API 키는 브라우저에 넣지 않습니다.

로컬 콘솔은 이미 로그인된 Codex CLI를 읽기 전용·임시 세션으로 호출합니다. 공개 RSS의 제목·요약·링크와 회사 평가표만 편집회의에 전달하며, 옵시디언의 다른 개인 문서는 전달하지 않습니다. 편집 결과가 20개 전수 평가나 품질 기준을 만족하지 못하면 저품질 대체 글을 만들지 않고 오류를 표시합니다.
